== Description ==

Worang Client Companion is an optional WordPress plugin for sites that use @worang/wordpress-client.
It exposes public helper endpoints for SDK feature detection and cache invalidation.

== Installation ==

1. Build or download the plugin zip.
2. In WordPress admin, go to Plugins > Add New > Upload Plugin.
3. Select worang-client-companion.zip and install it.
4. Activate the plugin.

== FAQ ==

= Do I need this plugin? =

Only if you use @worang/wordpress-client and want cache invalidation support.
